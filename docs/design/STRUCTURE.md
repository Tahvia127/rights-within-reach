# Site structure & flow — civic-service direction

**Direction:** structure and clarity of a civic/government service site
(nyc.gov · GovForAmerica · VoteFwd) — task-first, information-rich, usable by anyone —
rendered in **your** brand: Fraunces + Inter, midnight / burgundy / clover / bone, with a
**bold photo-driven hero** (Humanity) and **earthy-clean cards** (Lovelyacts). No doodles.

Guiding rule from those sites: **context → how it works → proof/trust → a clear directory
of tasks → the next action.** Understanding first, then action.

---

## 1. The three people who land here (design the flow around these)
1. **"I have a problem right now"** → needs to *ask* and get a plain, cited answer. → Hero CTA + Ask.
2. **"I want to understand my rights"** → needs to *browse* a topic. → Topic directory.
3. **"I need a real person / phone number"** → needs a *referral*. → Find help near you + Resources.

Every home section serves one of these. Nothing decorative.

## 2. Navigation (keep, cleaned)
- **Primary:** Home · Topics (Housing · Money · Repairs · Benefits) · Resources · **Ask a question** (CTA)
- **Utility (always visible):** 5 languages · A+ · high-contrast · read-aloud
- **Mobile:** fixed bottom nav (Housing · Money · Repairs · Benefits · Resources · Ask)

## 3. Home page flow (the new section order)
| # | Section | Job it does | Civic pattern |
|---|---|---|---|
| 1 | **Hero** | Headline "Know your rights." + one plain line + **Ask a question** (primary) & **Browse topics** (secondary) + a warm photo of a real person | GovForAmerica hero + CTA |
| 2 | **Choose what you need** | The 4 topics as a clear, scannable card grid (icon + name + one line + "Learn more") — the main directory | nyc.gov service grid |
| 3 | **How it works** | 3 plain steps: Ask in your language → Get a cited answer → Get connected to real help | VoteFwd how-it-works |
| 4 | **Why you can trust this** | Trust band: cites the law · 5 languages · free, no login · checked daily | Civic trust signals |
| 5 | **Find help near you** | Area picker → verified free orgs by region (already built) | "Find services near you" |
| 6 | **Real organizations** | Teaser of the ~44-org directory → link to Resources | nyc.gov directory |
| 7 | **Who this is for / reassurance** | Plain "This is for you if…" + the info-not-advice disclaimer | Plain-language close |
| — | Footer | Topics · Help · About · disclaimer | — |

## 4. Cohesion rules (so the whole site feels like one thing)
- **One section rhythm:** every section = eyebrow → serif heading → (read-aloud) → content, with
  the **same vertical spacing** and the **same max-width** container. Even spacing everywhere.
- **Alternating backgrounds** only (bone ↔ cream), never more than one accent color per section.
- **Cards are one component:** same radius (14px), same padding, same icon-chip size — reused for
  topics, resources, trust, help. Even imagery.
- **Photos** follow `IMAGERY-LIST.md` (same aspect ratios + treatment).
- **Plain language, 6th-grade**, short lines, big tap targets, works in all 5 languages and in
  large-text / high-contrast modes.

## 5. Same pattern for the inner pages
- **Topic pages** (Housing/Money/Repairs/Benefits): hero (photo + title) → summary → FAQs →
  programs → steps → "find help" → referral. Same section rhythm as home.
- **Resources:** find-help-near-me → featured orgs → categorized directory → "what to bring".
- **Chat:** unchanged flow (triage → cited answer card → contact → feedback).
